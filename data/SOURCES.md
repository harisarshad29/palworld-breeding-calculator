# Breeding data provenance

`pals.json`, `breeding_table.json`, and `special_combos.json` are generated by
`scripts/import_palcalc.py` from Tyler Camp's PalCalc repository, pinned to commit
`66f18a000e2107640b219562437357ced5aff7eb`.

Source: https://github.com/tylercamp/palcalc/tree/66f18a000e2107640b219562437357ced5aff7eb

Imported on 25 October 2026. The snapshot contains 299 species and 44,851 outcomes
covering 44,850 unordered parent pairs. One pair has two gender-dependent outcomes.
The upstream snapshot does not declare a game build, so the site does not claim
that the import independently verifies the latest game release.

The compact child-index table preserves upstream outcomes rather than
approximating the breeding-power formula. This preserves special-only species,
same-species results, source priority/tie-breaking decisions, and both Katress /
Wixen gender outcomes. The flower form of Gumoss is labelled `Gumoss (Flower)` to
keep the two upstream records and their routes distinct.

The import replays every upstream outcome and rejects incomplete coverage. Source
SHA-256 hashes and counts are recorded in `provenance.json`. `special_combos.json`
is a convenience index of fixed cross-species pairs whose child has exactly one
cross-species row; it is not used as the complete calculation engine. All
calculations use `breeding_table.json`.

Run `python scripts/import_palcalc.py` to reproduce this pinned import. A data
refresh requires deliberately changing the pinned commit and reviewing/retesting
the results. No automatic fetch occurs during application startup or deployment.

PalCalc is MIT licensed; the retained notice is in `licenses/PalCalc-MIT.txt`.
The existing map notes, item references, technology notes, and illustration assets
have separate coverage and were not imported or verified by this breeding-data
refresh. Missing images use the bundled placeholder. Mutations, passive traits,
individual stats, and gender inventory constraints are outside the planner model.
